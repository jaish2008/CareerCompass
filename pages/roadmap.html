Development plan, scope and milestones for CareerCompass.

Project Scope

A single, software-only web platform for placement preparation

CareerCompass is built end-to-end as a web application — no external hardware or IoT components are used. Every module runs in the browser and shares one connected student profile, which is the core engineering focus of this project.

🚀 Future Scope

🧠 Smarter Scoring

Upgrade the interview scoring engine from keyword matching to a trained text-classification model (TF-IDF + logistic regression).

🔄 Self-Updating Question Bank

Scheduled refresh of interview questions via a free automated workflow, keeping content current without manual work.

📊 Deeper Analytics

Trend charts across all modules so a student can see improvement over months, not just a single attempt.

☁️ Optional Backend

Move from localStorage to a lightweight database so progress can be accessed across devices.
