# CareerCompass

CareerCompass is an AI-powered career guidance platform designed to help students and job seekers prepare for their careers through personalized learning, assessments, and skill development.

## Features

- AI-powered career recommendations
- Resume analysis and scoring
- GitHub profile analysis
- Technical and aptitude quizzes
- Mock interview preparation
- Personalized learning roadmap
- Internship tracker
- User authentication
- Dashboard with progress tracking

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- Pandas
- NumPy

## Installation

1. Clone the repository

```bash
git clone https://github.com/jaish2008/CareerCompass.git
```

2. Navigate to the project

```bash
cd CareerCompass
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Start the application

```bash
python app.py
```
